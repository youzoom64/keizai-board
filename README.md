# 経済ボード

日本の金利・為替・株価と、物価・賃金・雇用・GDPを1画面に並べる盤面。

**→ https://youzoom64.github.io/keizai-board/**

サーバーは要らない。GitHub Actions が1日2回データを取ってJSONにし、GitHub Pages が静的に配信する。

---

## 何のための道具か

「長期金利が上がった」と聞いた時に、その原因を自分で絞り込むための盤面。

金利の数字だけ見ても原因は分からない。同じ日に何が動いたかを横に並べて初めて、犯人が絞れる。

| 同時に起きたこと | 読み方 |
|---|---|
| 10年↑ かつ 2年↑ かつ 円高 | 日銀の利上げ期待が主因の形 |
| 10年↑ かつ 2年→ かつ 30年↑↑ | 財政・国債需給・長期インフレ懸念が主因の形 |
| 日本10年↑ と 米10年↑ が同じ幅 | 世界的な金利上昇。日本固有の材料では説明しきれない |

このパターン判定を機械にやらせて、根拠と一緒に画面の一番上に出す。断定はしない。「どの説明と整合するか」を出すだけで、最後に判断するのは読む人。

## 画面にあるもの

- **所見** — 上の判定を、根拠と数字つきで1行に
- **日次の盤面** — 7系列の最新値・前日比・1週・1ヶ月・3ヶ月、それに**異常度**（過去1年の日次変動σに対して今日が何倍動いたか。2σ超は色が付く）
- **月次・四半期の盤面** — 13系列
- **グラフ** — 期間8段階＋任意の開始日/終了日、表示3モード、日銀会合の縦線、カーソルでその日の値
- **盤面をコピー** — 表と所見をmarkdownで写す。AIに貼って質問する用

### グラフの表示モード

金利(2.9%)・ドル円(159円)・日経平均(66,000円)は桁が違う。実数のまま重ねると日経の線だけが目立って他が平らに見えるので、既定では全部を「開始日からどれだけ動いたか」に揃えている。

| モード | 何を描くか |
|---|---|
| 開始日からの動き（既定） | 開始日を0として、金利はbp、株や為替は%で |
| 開始日を100とした指数 | 開始日を100として何倍になったか |
| 実数（そのままの値） | 66,098円のような生の値。単位ごとに左右の軸へ分ける |

同じ軸に載せた系列の値幅が5倍以上開くと「この縮尺では平らに見える」と警告を出す。

## 収録している系列

| 分類 | 系列 |
|---|---|
| 金利 | 日本2年・10年・30年国債、米10年国債 |
| 為替・株・商品 | ドル円、日経平均、WTI原油 |
| 物価 | コアCPI、総合CPI、コアコアCPI、国内企業物価、輸入物価（円建/契約通貨建）、輸出物価（円建/契約通貨建） |
| 賃金 | 実質賃金、名目賃金 |
| 雇用 | 完全失業率、有効求人倍率 |
| 景気 | 実質GDP（前期比年率） |
| 日程 | 日銀 金融政策決定会合（2010年〜） |

国債は1974年から。輸入物価の円建と契約通貨建の差を見ると、輸入インフレのうち**円安由来がどれだけか**が分かる。

## 出典

いずれも各機関の公表値。加工（差分の計算・σ・パターン判定）はこのリポジトリが行っている。

- [財務省 国債金利情報](https://www.mof.go.jp/jgbs/reference/interest_rate/) — 国債利回り
- [統計ダッシュボード](https://dashboard.e-stat.go.jp/)（総務省ほか） — 物価・賃金・雇用・GDP
- [日本銀行](https://www.boj.or.jp/mopo/mpmsche_minu/) — 金融政策決定会合の日程
- [FRED](https://fred.stlouisfed.org/)（セントルイス連銀） — 米10年国債・WTI原油・ドル円・日経平均

日経平均の指数値は日本経済新聞社の著作物。参考として表示しているだけで、再配布を目的としたものではない。

**投資判断に使うための道具ではない。** 数値の正確性は保証しない。必ず一次資料で確認すること。

## 仕組み

```
GitHub Actions（1日2回・cron）
  └ collector/ の Python が各所からデータを取得
     └ docs/data/*.json を書き出して commit
        └ GitHub Pages が静的配信
           └ ブラウザの JS が JSON を読んで描画
```

ブラウザから財務省やFREDを直接叩くのはCORSで弾かれるので、取得はActions側でやる。結果として利用者は静的ファイルを読むだけで済み、表示が速い。

```
collector/
  series.py    系列レジストリ。系列を足す時はここに1行足すだけ
  sources.py   取得元ごとの取り方（財務省CSV / 統計ダッシュボード / FRED / Yahoo）
  store.py     SQLite。縦持ち1テーブル
  collect.py   取得ラン。代替元へのフォールバックつき
  analyze.py   差分・σ・パターン判定
  boj.py       日銀の会合日程
  export.py    docs/data/*.json の書き出し
docs/          GitHub Pages のルート。index.html + app.js + style.css + data/
```

## 手元で動かす

```bash
pip install -r collector/requirements.txt
python -m collector.export          # 取得して docs/data/*.json を書き出す
python -m http.server -d docs 8000  # http://127.0.0.1:8000/
```

`python -m collector.analyze` だけを叩けば、盤面をテキストで出力する。
